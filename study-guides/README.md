# AWS Solutions Architect study guides

These 14 guides structure the raw Skill Builder transcripts. The originals in [`skillbuilder/`](../skillbuilder/) are unchanged.

## How to study

1. Read the scope and study points.
2. Use the trade-off tables to practice requirement-driven service selection.
3. Answer every retained host question before reading its answer.
4. Verify current limits, pricing, and features in the official references.
