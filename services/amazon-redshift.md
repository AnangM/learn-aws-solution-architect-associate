# Amazon Redshift

## What the Service Is
Amazon Redshift is a fast, scalable, fully managed cloud data warehouse that makes it simple and cost-effective to analyze all your data using standard SQL and business intelligence tools.

## Description of the Service
Redshift uses columnar storage, massive parallel processing (MPP), and data compression to execute complex analytical queries across petabytes of structured and semi-structured data. Redshift RA3 nodes decouple compute and storage using managed storage backed by Amazon S3. Redshift Spectrum allows direct SQL querying against open-format data in Amazon S3 data lakes without loading data into clusters.

## When to Use the Service
- Use Amazon Redshift for enterprise data warehousing, business intelligence reporting, and historical trend analytics across gigabytes to petabytes of data.
- Use Amazon Redshift Serverless for ad-hoc, intermittent, or variable analytical querying without managing warehouse clusters.
