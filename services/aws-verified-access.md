# AWS Verified Access

## What the Service Is
AWS Verified Access provides secure corporate application access without requiring a traditional VPN, adhering to Zero Trust principles.

## Description of the Service
Verified Access evaluates every application request in real time against corporate identity (IAM Identity Center, Okta) and device security posture (CrowdStrike, Jamf) before granting access, eliminating the need for legacy client VPN software.

## When to Use the Service
- Use AWS Verified Access to implement Zero Trust application access for remote workforces accessing internal corporate web applications.
