# AWS Firewall Manager

## What the Service Is
AWS Firewall Manager is a security management service that allows you to centrally configure and manage firewall rules across your accounts and applications in AWS Organizations.

## Description of the Service
As new applications and accounts are created, Firewall Manager automatically applies pre-configured security policies across resources. It manages AWS WAF rules, AWS Shield Advanced protections, Amazon VPC security groups, and AWS Network Firewall rules from a single centralized administrator account.

## When to Use the Service
- Use AWS Firewall Manager when managing security compliance and firewall policies across multiple AWS accounts in an enterprise AWS Organization.
