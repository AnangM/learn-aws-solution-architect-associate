# AWS Database Migration Service (AWS DMS)

## What the Service Is
AWS DMS is a managed migration and replication service that helps you migrate databases and analytics workloads to AWS quickly and securely with minimal downtime.

## Description of the Service
AWS DMS supports homogeneous migrations (e.g., Oracle to Oracle) as well as heterogeneous migrations between different database engines (e.g., Oracle to PostgreSQL or SQL Server to Aurora MySQL) using the AWS Schema Conversion Tool (SCT). It supports continuous data capture (CDC) to keep source and target databases in sync during migration.

## When to Use the Service
- Use AWS DMS for database migration from on-premises to AWS with near-zero downtime.
- Use AWS DMS for continuous data replication from production transactional databases into S3 data lakes or Amazon Redshift.
