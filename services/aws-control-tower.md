# AWS Control Tower

## What the Service Is
AWS Control Tower provides the easiest way to set up and govern a secure, multi-account AWS environment (a landing zone) based on AWS best practices.

## Description of the Service
Control Tower automates the creation of a well-architected multi-account environment using AWS Organizations. It configures pre-defined guardrails (preventive via SCPs and detective via AWS Config), establishes an Account Factory for self-service account provisioning, and configures centralized identity with IAM Identity Center.

## When to Use the Service
- Use AWS Control Tower when creating a new enterprise cloud foundation or automating multi-account governance with built-in landing zone architecture.
