# AWS Auto Scaling (Unified)

## What the Service Is
AWS Auto Scaling is a unified service that monitors your applications and automatically adjusts capacity to maintain steady, predictable performance at the lowest possible cost across multiple resource types.

## Description of the Service
Unlike EC2 Auto Scaling (which scales only EC2 instances), AWS Auto Scaling creates unified scaling plans that coordinate scaling across multiple AWS services simultaneously: Amazon EC2 Auto Scaling groups, Amazon ECS services, Amazon DynamoDB tables/indexes, and Amazon Aurora Read Replicas.

## When to Use the Service
- Use AWS Auto Scaling when you want a single unified scaling strategy that optimizes performance and cost across your entire multi-tier application stack in lockstep.
