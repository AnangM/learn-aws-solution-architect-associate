# AWS Elastic Beanstalk

## What the Service Is
AWS Elastic Beanstalk is an easy-to-use orchestration service for deploying and scaling web applications and services developed with Java, .NET, PHP, Node.js, Python, Ruby, Go, and Docker on familiar servers such as Apache, Nginx, Passenger, and IIS.

## Description of the Service
You simply upload your code, and Elastic Beanstalk automatically handles deployment, provisioning, load balancing, auto-scaling, and application health monitoring. Unlike serverless platforms, Beanstalk retains full customer control over the underlying AWS resources (EC2 instances, databases, security groups).

## When to Use the Service
- Use Elastic Beanstalk when you want fast deployment of traditional multi-tier web applications while preserving access to and control over the underlying EC2 instances.
- Use Elastic Beanstalk for legacy monolithic web applications undergoing initial cloud migration.
