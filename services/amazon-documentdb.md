# Amazon DocumentDB

## What the Service Is
Amazon DocumentDB (with MongoDB compatibility) is a fully managed, native JSON document database service designed for scale, durability, and high availability.

## Description of the Service
DocumentDB uses a decoupled architecture similar to Aurora, replicating data six times across three Availability Zones. It provides MongoDB 3.6/4.0/5.0 API compatibility, automated backups, and built-in security.

## When to Use the Service
- Use Amazon DocumentDB when migrating existing MongoDB workloads to a fully managed AWS service without rewriting application code.
- Use Amazon DocumentDB for applications requiring JSON document schemas with nested attributes and rich indexing.
