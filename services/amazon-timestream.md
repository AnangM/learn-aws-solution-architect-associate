# Amazon Timestream

## What the Service Is
Amazon Timestream is a fast, scalable, and serverless time-series database service for IoT and operational applications.

## Description of the Service
Timestream automatically tiers data between an in-memory store for recent data and a magnetic store for historical data based on user-defined retention policies. It processes trillions of events daily with built-in analytical query functions.

## When to Use the Service
- Use Amazon Timestream for IoT sensor telemetry, DevOps monitoring metrics, application clickstream data, and industrial equipment tracking.
