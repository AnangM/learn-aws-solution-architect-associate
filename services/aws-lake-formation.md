# AWS Lake Formation

## What the Service Is
AWS Lake Formation is a service that makes it easy to set up, secure, and manage a centralized data lake on Amazon S3.

## Description of the Service
Lake Formation simplifies and automates many complex manual steps usually required to create a data lake: collecting, cleaning, and cataloging data, and enforcing centralized, fine-grained access control policies (down to the database, table, column, and row level) across analytics engines (Athena, Redshift, EMR).

## When to Use the Service
- Use AWS Lake Formation to establish governance, audit trails, and granular column/row-level permissions on data lakes stored in Amazon S3.
