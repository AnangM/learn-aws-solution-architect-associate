# AWS Audit Manager

## What the Service Is
AWS Audit Manager helps you continuously audit your AWS usage to simplify how you assess risk and compliance with regulations and industry standards.

## Description of the Service
Audit Manager automates evidence collection from AWS services (Config, CloudTrail, Security Hub) and maps it against compliance frameworks (PCI-DSS, HIPAA, GDPR, NIST), generating audit-ready reports.

## When to Use the Service
- Use AWS Audit Manager to streamline regulatory compliance assessments and automate continuous evidence gathering.
