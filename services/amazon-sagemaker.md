# Amazon SageMaker

## What the Service Is
Amazon SageMaker is a fully managed service that provides every developer and data scientist with the ability to build, train, and deploy machine learning (ML) models quickly.

## Description of the Service
SageMaker covers the entire ML lifecycle: data labeling (Ground Truth), feature engineering, distributed training, hyperparameter tuning, model deployment (endpoints), and model monitoring.

## When to Use the Service
- Use Amazon SageMaker when developing, training, and hosting machine learning models on managed infrastructure at scale.
