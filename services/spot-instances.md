# Amazon EC2 Spot Instances

## What the Service Is
Amazon EC2 Spot Instances allow you to take advantage of unused EC2 capacity in the AWS Cloud at steep discounts of up to 90% off On-Demand pricing.

## When to Use It
- Use Spot Instances for stateless, fault-tolerant, containerized (ECS/EKS), or batch processing workloads (AWS Batch, EMR) that can gracefully handle instance interruptions with a 2-minute notice.
