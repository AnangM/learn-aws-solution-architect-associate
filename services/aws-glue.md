# AWS Glue

## What the Service Is
AWS Glue is a serverless data integration service that makes it easy to discover, prepare, move, and integrate data from multiple sources for analytics, machine learning, and application development.

## Description of the Service
AWS Glue provides visual and code-based interfaces for data preparation and ETL. Core components include Glue Crawlers (which scan data stores to infer schemas), the AWS Glue Data Catalog (a central metadata repository), Glue ETL (serverless Apache Spark code execution), and Glue DataBrew (visual data cleaning).

## When to Use the Service
- Use AWS Glue to catalog datasets in Amazon S3, RDS, DynamoDB, and on-premises databases for query engines like Athena, Redshift Spectrum, and EMR.
- Use AWS Glue ETL for serverless batch and streaming data transformation jobs without managing Spark clusters.
