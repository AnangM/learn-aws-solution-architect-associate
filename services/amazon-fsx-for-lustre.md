# Amazon FSx for Lustre

## What the Service Is
Amazon FSx for Lustre is a fully managed, high-performance parallel file system optimized for fast processing of compute-intensive workloads.

## Description of the Service
Lustre delivers sub-millisecond latencies, hundreds of gigabytes per second of throughput, and millions of IOPS. It seamlessly links to Amazon S3 buckets, presenting S3 objects as files that can be processed directly by HPC clusters with changes synchronized back to S3.

## When to Use the Service
- Use Amazon FSx for Lustre for High-Performance Computing (HPC), machine learning training, financial modeling, autonomous vehicle simulation, and video rendering pipelines.
- Use FSx for Lustre linked to S3 for temporary burst processing of large object datasets.
