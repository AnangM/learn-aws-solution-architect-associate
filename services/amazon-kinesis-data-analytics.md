# Amazon Managed Service for Apache Flink (formerly Kinesis Data Analytics)

## What the Service Is
Amazon Managed Service for Apache Flink enables real-time stream analytics on data in motion using SQL, Java, or Scala without managing servers.

## Description of the Service
It continuously reads from streaming sources (Kinesis Data Streams, Amazon MSK), runs stateful stream processing, sliding window aggregations, and real-time filtering, and emits results to target destinations.

## When to Use the Service
- Use Managed Service for Apache Flink when applications require real-time anomaly detection, complex event processing, and streaming metrics on data in motion.
