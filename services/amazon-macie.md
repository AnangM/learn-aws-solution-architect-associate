# Amazon Macie

## What the Service Is
Amazon Macie is a fully managed data security and privacy service that uses machine learning and pattern matching to discover, classify, and protect sensitive data in Amazon S3.

## Description of the Service
Macie automates the discovery of Personally Identifiable Information (PII)—such as names, addresses, credit card numbers, social security numbers, passport numbers, and AWS credentials—stored in S3 buckets. It evaluates bucket-level security controls (detecting unencrypted, public, or shared buckets) and generates security findings.

## When to Use the Service
- Use Amazon Macie to discover, inventory, and protect PII, financial data, and credentials stored in Amazon S3 buckets for regulatory compliance (GDPR, HIPAA, PCI-DSS).
