# Amazon Neptune

## What the Service Is
Amazon Neptune is a fast, reliable, fully managed graph database service optimized for storing and querying highly connected datasets.

## Description of the Service
Neptune supports open graph query frameworks including Apache TinkerPop Gremlin, W3C SPARQL, and openCypher. Built on the Aurora-style decoupled storage engine, it replicates data across 3 AZs and scales read replicas up to 15 nodes.

## When to Use the Service
- Use Amazon Neptune for fraud detection, social networking graphs, knowledge graphs, recommendation engines, and network security mapping where relationships between entities are paramount.
