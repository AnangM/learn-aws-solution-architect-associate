# Amazon S3 Express One Zone

## What the Service Is
Amazon S3 Express One Zone is a high-performance, single-AZ storage class designed to deliver consistent single-digit millisecond data access for latency-sensitive applications.

## Description of the Service
S3 Express One Zone provides data access speeds up to 10x faster and request costs 50% lower than S3 Standard by co-locating storage in directory buckets within a single Availability Zone.

## When to Use the Service
- Use S3 Express One Zone for machine learning training iterations, interactive analytics, and high-frequency transactional data processing where sub-10ms latency is mandatory.
