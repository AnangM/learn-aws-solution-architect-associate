# AWS Cloud WAN

## What the Service Is
AWS Cloud WAN is a managed wide area networking (WAN) service that connects on-premises branch offices, data centers, and Amazon VPCs into a single global unified network.

## Description of the Service
Cloud WAN replaces manual multi-region Transit Gateway peering with a centralized, declarative network policy document. It automatically provisions and manages global routing across AWS regions and edge locations.

## When to Use the Service
- Use AWS Cloud WAN for enterprise-scale global wide area networks spanning multiple continents, branch offices, and AWS regions under a single unified network policy.
