# Amazon Comprehend

## What the Service Is
Amazon Comprehend is a natural language processing (NLP) service that uses machine learning to uncover valuable insights and connections in unstructured text.

## Description of the Service
Comprehend analyzes text documents to extract entities, key phrases, language, sentiment (positive, negative, neutral), and PII data without requiring machine learning expertise.

## When to Use the Service
- Use Amazon Comprehend for automated customer feedback sentiment analysis, IT support ticket triage/categorization, and scanning text documents for sensitive PII.
