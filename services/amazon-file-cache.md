# Amazon File Cache

## What the Service Is
Amazon File Cache is a fully managed, high-speed temporary cache on AWS that makes it easy to process file data regardless of where the data is stored (on-premises, AWS, or other clouds).

## Description of the Service
Backed by Lustre technology, Amazon File Cache presents a unified POSIX namespace to cloud compute resources with sub-millisecond latencies and high throughput, transparently caching datasets originating from on-premises NFS file systems or Amazon S3 buckets.

## When to Use the Service
- Use Amazon File Cache when cloud compute clusters (EC2, ECS, EKS) need to burst-process datasets stored on on-premises NFS storage systems or S3 without migrating the primary storage.
