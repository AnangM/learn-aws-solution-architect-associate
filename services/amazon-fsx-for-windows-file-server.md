# Amazon FSx for Windows File Server

## What the Service Is
Amazon FSx for Windows File Server provides fully managed, highly reliable shared file storage that is accessible over the industry-standard Server Message Block (SMB) protocol.

## Description of the Service
Built on Windows Server, it provides native Windows file system compatibility: NTFS file permissions, Microsoft Active Directory integration, Distributed File System (DFS) namespaces, data deduplication, shadow copies, and Multi-AZ deployments.

## When to Use the Service
- Use FSx for Windows File Server when Windows applications, .NET workloads, or corporate users require shared SMB file storage.
- Use FSx for Windows File Server for Microsoft SQL Server High Availability Always On Failover Cluster Instances (FCI).
