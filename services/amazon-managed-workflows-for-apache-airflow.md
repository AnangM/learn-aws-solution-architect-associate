# Amazon Managed Workflows for Apache Airflow (Amazon MWAA)

## What the Service Is
Amazon MWAA is a managed orchestration service for Apache Airflow that makes it easy to set up and operate end-to-end data pipelines in the cloud.

## Description of the Service
MWAA uses Python Direct Acyclic Graphs (DAGs) to automate complex workflow scheduling, dependency management, and monitoring across disparate data platforms, with automated scaling and built-in AWS IAM security.

## When to Use the Service
- Use Amazon MWAA when engineering teams use Apache Airflow DAGs for orchestrating complex, multi-system ETL pipelines across AWS and third-party tools.
