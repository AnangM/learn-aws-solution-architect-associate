# AWS App Runner

## What the Service Is
AWS App Runner is a fully managed container application service that makes it easy for developers to quickly deploy web applications and APIs at scale without prior infrastructure experience.

## Description of the Service
App Runner takes your source code (from GitHub) or container image (from Amazon ECR) and automatically builds, deploys, load-balances, and scales the application container instances. It manages TLS certificates, traffic routing, health checks, and auto-scaling based on concurrent requests.

## When to Use the Service
- Use AWS App Runner when you want the absolute simplest containerized web app or API deployment without configuring VPC subnets, ALBs, ECS task definitions, or Kubernetes manifests.
- Use AWS App Runner for small-to-medium web applications, backend APIs, and microservices where developer speed is prioritized over complex infrastructure customization.
