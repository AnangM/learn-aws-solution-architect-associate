# Amazon S3 Storage Lens

## What the Service Is
Amazon S3 Storage Lens is a cloud storage analytics feature that provides organization-wide visibility into object storage usage and activity trends.

## Description of the Service
Storage Lens provides interactive dashboards with actionable metrics and cost-optimization recommendations across entire AWS Organizations, specific accounts, regions, or buckets.

## When to Use the Service
- Use S3 Storage Lens to identify optimization opportunities: finding unattached incomplete multipart uploads, auditing encryption compliance, and discovering buckets missing lifecycle rules.
