# AWS CloudFormation

## What the Service Is
AWS CloudFormation is an Infrastructure as Code (IaC) service that allows you to model, provision, and manage AWS and third-party resources using declarative templates.

## Description of the Service
CloudFormation treats infrastructure as software code written in JSON or YAML. It provisions resources in the correct dependency order, handles rollback on failure, detects configuration drift, and supports multi-region, multi-account deployments using CloudFormation StackSets.

## When to Use the Service
- Use AWS CloudFormation to automate the consistent, reproducible provisioning of complete cloud architectures across environments (dev, staging, prod).
- Use CloudFormation StackSets to deploy baseline security and networking resources across all accounts in an AWS Organization.
