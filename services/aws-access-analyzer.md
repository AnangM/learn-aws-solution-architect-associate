# IAM Access Analyzer

## What the Service Is
IAM Access Analyzer is an AWS IAM capability that helps identify the resources in your organization and accounts (such as S3 buckets, KMS keys, SQS queues, and IAM roles) that are shared with an external entity.

## Description of the Service
Access Analyzer uses automated mathematical reasoning to inspect resource-based policies and identify public or cross-account access paths that cross account or organization trust boundaries.

## When to Use the Service
- Use IAM Access Analyzer to detect unintended public or cross-account access to critical resources and validate IAM policies against security baselines.
