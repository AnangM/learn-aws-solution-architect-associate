# AWS Resilience Hub

## What the Service Is
AWS Resilience Hub provides a central place to define, validate, and track the resilience of your AWS applications against disruptions.

## Description of the Service
Resilience Hub assesses your application architecture against defined RTO and RPO objectives, identifies architectural weaknesses, and generates standard operating procedures (SOPs) and AWS FIS chaos experiments.

## When to Use the Service
- Use AWS Resilience Hub to audit application resilience, eliminate single points of failure, and verify adherence to disaster recovery targets.
