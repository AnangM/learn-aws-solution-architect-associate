# Amazon OpenSearch Service

## What the Service Is
Amazon OpenSearch Service is a fully managed service that makes it easy to perform interactive log analytics, real-time application monitoring, and website search using OpenSearch and legacy Elasticsearch.

## Description of the Service
OpenSearch Service provisions and manages search clusters, supporting full-text search, faceted search, vector search for AI, and real-time dashboard visualization via OpenSearch Dashboards.

## When to Use the Service
- Use Amazon OpenSearch Service for real-time application and infrastructure log analytics (ingesting from CloudWatch, Kinesis, or Logstash).
- Use Amazon OpenSearch Service when web applications require low-latency full-text search and filtering across unstructured product catalogs.
