# AWS Network Manager

## What the Service Is
AWS Network Manager (Transit Gateway Network Manager and Cloud WAN) provides a single global dashboard to visualize, monitor, and troubleshoot your global network.

## Description of the Service
It aggregates topology maps, CloudWatch metrics, connection health, and event logs across Transit Gateways, VPNs, Direct Connect links, and on-premises SD-WAN devices.

## When to Use the Service
- Use AWS Network Manager for unified operational visibility and troubleshooting across hybrid cloud networks.
