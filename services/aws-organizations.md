# AWS Organizations

## What the Service Is
AWS Organizations is an account management service that enables you to consolidate multiple AWS accounts into an organization that you create and centrally govern.

## Description of the Service
Organizations provides centralized billing (consolidated billing), shared resource management via AWS RAM, and policy-based controls. It organizes accounts into a hierarchy of Organizational Units (OUs) and uses Service Control Policies (SCPs) to set permission guardrails across member accounts.

## When to Use the Service
- Use AWS Organizations when managing multi-account cloud environments for enterprise security, compliance isolation, and consolidated billing discounts.
- Use Service Control Policies (SCPs) to enforce organization-wide boundaries (e.g., disallowing the disabling of CloudTrail or restricting deployment to specific AWS regions).
