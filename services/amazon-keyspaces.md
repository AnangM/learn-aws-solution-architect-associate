# Amazon Keyspaces

## What the Service Is
Amazon Keyspaces is a scalable, highly available, and managed Apache Cassandra-compatible database service.

## Description of the Service
Keyspaces is serverless, meaning you pay only for the resources you use. It supports the Cassandra Query Language (CQL) API and automatically replicates data three times across multiple Availability Zones.

## When to Use the Service
- Use Amazon Keyspaces when migrating Apache Cassandra workloads to AWS to eliminate the operational complexity of managing Cassandra clusters.
