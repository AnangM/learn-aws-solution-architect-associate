# Amazon S3 Transfer Acceleration

## What the Service Is
Amazon S3 Transfer Acceleration enables fast, easy, and secure transfers of files over long distances between your client and an S3 bucket.

## Description of the Service
It takes advantage of Amazon CloudFront globally distributed Edge Locations. Data uploaded to an S3 bucket is routed to the nearest edge location over public internet, and then travels over AWS's optimized private network backbone to the destination bucket.

## When to Use the Service
- Use S3 Transfer Acceleration when customers or distributed offices globally upload large files (>100 MB) across continents into a centralized S3 bucket.
