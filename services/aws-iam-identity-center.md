# AWS IAM Identity Center (formerly AWS SSO)

## What the Service Is
AWS IAM Identity Center is the recommended central service for managing workforce access to multiple AWS accounts and cloud business applications.

## Description of the Service
IAM Identity Center connects to your existing corporate identity provider (Microsoft Active Directory, Azure AD, Okta, Ping, Google Workspace) via SAML 2.0 or SCIM, or manages users in its built-in directory. It provides a centralized user portal where users sign in once and gain federated, temporary STS role access to assigned AWS accounts and permission sets.

## When to Use the Service
- Use AWS IAM Identity Center as the standard, modern solution for human workforce authentication and single sign-on (SSO) across multi-account AWS Organizations.
- Use IAM Identity Center when federating enterprise Active Directory or Okta users without provisioning individual IAM users in each AWS account.
