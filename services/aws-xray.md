# AWS X-Ray

## What the Service Is
AWS X-Ray is a distributed tracing and observability service that helps developers analyze and debug distributed applications, such as those built using a microservices architecture.

## Description of the Service
X-Ray provides an end-to-end view of requests as they travel through your application. It generates a Service Map showing latency bottlenecks, downstream database calls, and error/fault percentages across microservices, Lambda functions, and API Gateways.

## When to Use the Service
- Use AWS X-Ray when debugging latency bottlenecks, errors, and performance anomalies in complex microservices or serverless architectures.
