# Amazon MQ

## What the Service Is
Amazon MQ is a managed message broker service for open-source message queuing software: Apache ActiveMQ and RabbitMQ.

## Description of the Service
Amazon MQ manages the provisioning, setup, patching, and high availability of message brokers. It supports standard industry messaging protocols including JMS, NMS, AMQP 0-9-1, AMQP 1.0, STOMP, MQTT, and OpenWire.

## When to Use the Service
- Use Amazon MQ when migrating existing on-premises message-broker applications (using ActiveMQ or RabbitMQ) to AWS without rewriting messaging application code to use SQS/SNS.
