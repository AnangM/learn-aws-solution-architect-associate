# AWS Client VPN

## What the Service Is
AWS Client VPN is a managed client-based VPN service that enables remote workers to securely access AWS resources and on-premises networks using OpenVPN-based desktop clients.

## Description of the Service
Client VPN automatically scales up and down based on the number of connected users. It integrates with Active Directory, Okta, and AWS IAM Identity Center for authentication, and provides certificate-based mutual authentication.

## When to Use the Service
- Use AWS Client VPN when individual remote employees, developers, or system administrators need secure, encrypted remote access to resources inside private AWS VPCs from laptops or home computers.
