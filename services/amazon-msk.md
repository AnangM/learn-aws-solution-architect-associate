# Amazon Managed Streaming for Apache Kafka (Amazon MSK)

## What the Service Is
Amazon MSK is a fully managed service that makes it easy to build and run applications that use Apache Kafka to process streaming data.

## Description of the Service
Amazon MSK manages the setup, scaling, and operations of Apache Kafka clusters. It provides multi-AZ replication, automated broker recovery, encryption at rest and in transit, and native AWS security integration.

## When to Use the Service
- Use Amazon MSK when applications require open-source Apache Kafka compatibility, existing Kafka producer/consumer code, or custom Kafka ecosystem tools (Kafka Connect, Schema Registry) without managing Kafka servers.
