# Amazon EMR

## What the Service Is
Amazon EMR is the industry-leading cloud big data platform for data processing, interactive analysis, and machine learning using open-source frameworks such as Apache Spark, Hadoop, Presto, and Hive.

## Description of the Service
Amazon EMR decouples compute and storage using Amazon S3 (EMRFS) as the persistent data lake. Clusters of EC2 instances (Primary, Core, and Task nodes) can be provisioned rapidly, scaled dynamically, and run on Spot Instances to achieve massive compute cost reductions. EMR can also run on EKS or Serverless.

## When to Use the Service
- Use Amazon EMR when running large-scale, distributed big data processing, computational analytics, machine learning, and ETL pipelines using native open-source Apache frameworks.
