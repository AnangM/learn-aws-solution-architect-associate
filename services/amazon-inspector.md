# Amazon Inspector

## What the Service Is
Amazon Inspector is an automated vulnerability management service that continuously scans AWS workloads for software vulnerabilities and unintended network exposure.

## Description of the Service
Inspector automatically discovers and scans running Amazon EC2 instances (using the AWS Systems Manager agent), container images in Amazon Elastic Container Registry (ECR), and AWS Lambda function code/dependencies. It correlates findings against Common Vulnerabilities and Exposures (CVE) databases and provides actionable vulnerability risk scores.

## When to Use the Service
- Use Amazon Inspector to automate continuous security scanning of EC2 instances, ECR container repositories, and Lambda functions during build, deployment, and runtime.
