# AWS VPN CloudHub

## What the Service Is
AWS VPN CloudHub is an AWS networking feature that provides secure communication between multiple remote branch offices using AWS as a central hub.

## Description of the Service
If you have multiple remote sites (branch offices, data centers) connected to an AWS Virtual Private Gateway or Transit Gateway via Site-to-Site VPN, CloudHub allows those remote branch offices to communicate directly with each other over the AWS network without establishing mesh VPN tunnels between each branch office.

## When to Use the Service
- Use AWS VPN CloudHub when you need a simple, low-cost hub-and-spoke branch office interconnection using existing IPsec VPN connections to AWS.
