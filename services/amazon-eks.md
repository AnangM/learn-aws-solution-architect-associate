# Amazon Elastic Kubernetes Service (Amazon EKS)

## What the Service Is
Amazon EKS is a managed Kubernetes service that makes it easy to run, manage, and scale containerized applications using standard Kubernetes on AWS.

## Description of the Service
Amazon EKS manages the availability and scalability of the Kubernetes control plane across three Availability Zones. It is upstream-certified, meaning applications running on standard open-source Kubernetes can run on EKS without code modification. Worker nodes can run on managed EC2 node groups, self-managed EC2 nodes, or AWS Fargate.

## When to Use the Service
- Use Amazon EKS when your organization has standardized on Kubernetes tooling, Helm charts, and open-source cloud-native ecosystems.
- Use Amazon EKS when multi-cloud portability between on-premises and AWS Kubernetes clusters is a core requirement.
