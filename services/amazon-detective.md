# Amazon Detective

## What the Service Is
Amazon Detective makes it easy to analyze, investigate, and quickly identify the root cause of potential security issues or suspicious activities.

## Description of the Service
Detective automatically collects log data from AWS resources (VPC Flow Logs, CloudTrail, GuardDuty findings) and uses machine learning and graph modeling to build interactive visual timelines showing user activity, IP traffic, and resource interactions over time.

## When to Use the Service
- Use Amazon Detective during security incident response investigations to triage GuardDuty findings and uncover the full blast radius of a security event.
