# AWS Batch

## What the Service Is
AWS Batch is a fully managed batch computing service that enables developers and engineers to easily and efficiently run hundreds of thousands of batch computing jobs on AWS.

## Description of the Service
AWS Batch dynamically provisions the optimal quantity and type of compute resources (EC2 or Fargate) based on the volume and specific resource requirements of the submitted batch jobs. It manages job queues, dependencies, priorities, retries, and compute environment lifecycles.

## When to Use the Service
- Use AWS Batch for large-scale, asynchronous computing workloads such as financial risk modeling, computational chemistry, video rendering, and deep learning data preprocessing.
- Use AWS Batch when jobs require complex multi-step dependency graphs and priority-based queue scheduling.
- Use AWS Batch with Spot Instances to achieve massive cost savings on fault-tolerant batch runs.
