# AWS Clean Rooms

## What the Service Is
AWS Clean Rooms helps companies and their partners more easily and securely collaborate and analyze their collective datasets without sharing or copying one another's underlying raw data.

## Description of the Service
Clean Rooms creates secure collaboration workspaces where multiple participants can run privacy-preserving SQL queries across datasets while enforcing mathematical privacy controls and query restrictions.

## When to Use the Service
- Use AWS Clean Rooms when multiple independent organizations (e.g., advertisers and publishers, financial partners) need to collaborate on joint data analytics without revealing raw customer PII to each other.
