# AWS Fault Injection Service (AWS FIS)

## What the Service Is
AWS FIS is a fully managed chaos engineering service that makes it easy to run controlled fault injection experiments on AWS workloads.

## Description of the Service
FIS allows you to simulate real-world faults—such as sudden CPU/memory spikes, database failovers, network latency, packet loss, or instance terminations—under controlled guardrails with automatic stop conditions.

## When to Use the Service
- Use AWS FIS to test and validate application fault tolerance, auto-scaling responsiveness, and failover recovery before outages occur in production.
