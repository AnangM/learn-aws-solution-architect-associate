# AWS DataSync

## What the Service Is
AWS DataSync is an online data movement and synchronization service that accelerates and automates transferring data between on-premises storage systems and AWS storage services, or between different AWS storage services.

## Description of the Service
DataSync uses a purpose-built network protocol to transfer data up to 10 times faster than open-source tools. It deploys an agent on-premises and automates data replication, data verification, scheduling, bandwidth throttling, and metadata preservation (permissions, timestamps, ownership).

## When to Use the Service
- Use AWS DataSync for high-speed online data migration, recurring synchronization, and scheduled disaster recovery replication between on-premises (NFS, SMB, HDFS, object stores) and AWS (S3, EFS, FSx).
- Use AWS DataSync for cross-account or cross-region file system data movement within AWS.
