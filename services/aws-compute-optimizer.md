# AWS Compute Optimizer

## What the Service Is
AWS Compute Optimizer recommends optimal AWS resources for your workloads to reduce costs and improve performance by using machine learning to analyze historical utilization metrics.

## Description of the Service
Compute Optimizer analyzes CloudWatch performance metrics (CPU, memory, storage, network) over the past 14 days (or up to 3 months with enhanced metrics) to identify underprovisioned or overprovisioned resources. It supports EC2 instances, EBS volumes, Lambda functions, and ECS tasks on Fargate.

## When to Use the Service
- Use AWS Compute Optimizer as the primary tool to right-size compute and storage resources before purchasing Savings Plans or Reserved Instances.
