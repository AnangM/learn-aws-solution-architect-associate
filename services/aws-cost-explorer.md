# AWS Cost Explorer

## What the Service Is
AWS Cost Explorer has an easy-to-use interface that lets you visualize, understand, and manage your AWS costs and usage over time.

## Description of the Service
Cost Explorer allows you to create custom interactive reports, view cost and usage trends, filter and group by dimensions (Account, Service, Region, Cost Allocation Tag), and view forecast spending for the next 12 months. It provides automated Reserved Instance (RI) and Savings Plans recommendations.

## When to Use the Service
- Use AWS Cost Explorer for interactive cost visualization, spending trends, chargeback reporting, and purchasing commitment discount recommendations.
