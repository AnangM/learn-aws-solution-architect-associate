# Amazon EC2 Reserved Instances (RIs)

## What the Service Is
Amazon EC2 Reserved Instances provide a significant discount (up to 72%) compared to On-Demand pricing in exchange for a 1- or 3-year commitment.

## When to Use It
- Use Standard RIs for steady-state, continuous 24/7 production workloads with predictable instance family and region requirements.
- Use Convertible RIs when 1- or 3-year commitments are acceptable but instance family, OS, or tenancy flexibility is needed.
