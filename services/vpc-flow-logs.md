# Amazon VPC Flow Logs

## What the Service Is
VPC Flow Logs is a feature that enables you to capture information about the IP traffic going to and from network interfaces in your VPC.

## When to Use the Service
- Use VPC Flow Logs to investigate security incidents, troubleshoot network connectivity and security group rule denials, and audit traffic flows. Data publishes to Amazon CloudWatch Logs, Amazon S3, or Amazon Kinesis Data Firehose.
