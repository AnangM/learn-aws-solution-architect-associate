# EC2 Image Builder

## What the Service Is
EC2 Image Builder is a fully managed AWS service that automates the creation, management, testing, and deployment of customized, secure, and compliant virtual machine (AMI) and container images.

## Description of the Service
Instead of manually configuring EC2 instances and capturing AMIs, Image Builder provides an automated pipeline. You define base OS images, select or author software components (build components), define validation tests (test components), and specify distribution regions and accounts.

## When to Use the Service
- Use EC2 Image Builder when your organization requires standardized, hardened Golden AMIs patched with latest security baselines.
- Use EC2 Image Builder to automate continuous image testing and multi-region, multi-account AMI distribution across AWS Organizations.
- Use EC2 Image Builder to maintain compliance and reduce operational overhead of building VM images manually.
